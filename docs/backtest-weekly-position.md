# 周线仓位表（回测①定稿）

> 结论：**高分池选股 + 纯周线档位定仓位** 是回测①验证出的最优形态。
> 回测 20 只高分池 × 10 万 × 4 年：策略 **+90.3%** vs 买入持有 **+87.3%**，
> 下跌票 **-0.7%**（持有 -45%），调仓 **96 笔**。

## 仓位表（全部占总资金绝对比例）

| 周线档位 | 仓位动作 | 空仓 | 持仓 |
|---------|---------|------|------|
| pullback_entry 周回调买入 | **100%** | 可建仓 | 调到 100% |
| strong_uptrend 周强上升 | **100%** | 可建仓 | 调到 100% |
| left_entry 周左侧 | **75%** | 可建仓 | 调到 75% |
| range 周中性 | **保持持仓** | 不买 | 保持 |
| weak_golden 周假金叉 | **减到 30%** | 不买 | 减到 30% |
| overheat 周过峰 | **减到 50%** | 不买 | 减到 50% |
| downtrend 周下跌 | **清仓 0%** | 不买 | 清仓 |
| insufficient 数据不足 | **清仓 0%** | 不买 | 清仓 |

## 规则

- **空仓**：只在买侧三档（pullback_entry / strong_uptrend / left_entry）建仓；
  其余档位空仓一律不买（尤其 weak_golden 假金叉不接刀、overheat 过峰不追高）。
- **持仓**：range 黏滞保持；weak_golden / overheat / downtrend / insufficient 按目标减/清。
- **成交口径**：信号当日 14:00 尾盘交易（按当日收盘价近似），信号日 = 成交日，无未来函数。
- **A 股 T+1**：当日买入次日才能卖出（批次 FIFO）；卖出回笼资金当日可再买入。

## 回测①完整结论（推导链）

1. **单票波段（日周综合 12 档滑条）跑不赢持有**：大牛股被日线风吹草动反复甩下车，
   任何减仓都砍牛股利润（上涨票仅 ~10-20% 跑赢）。
2. **日线越权翻转周线方向**是牛股磨损主因：矩阵 `(strong_uptrend, downtrend)`
   原映射 deep_rally_exit（清仓），周线向上却因日线回调被清仓 → 应改 `deep_pullback_entry`（加仓点）。
3. **评分选股有效**：综合分 ≥70 高分池持有 +87%（随机池仅 +50%）。
4. **择时是负贡献**：同样的高分池，日周综合波段 +65%，纯周线温和仓位 +90%（≈持有并保住止损）。
5. **最优组合 = 高分选股 + 纯周线温和仓位**。
